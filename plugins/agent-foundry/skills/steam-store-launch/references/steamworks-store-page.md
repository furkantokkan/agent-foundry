## Timing Rules

- A public Coming Soon page can collect wishlists before release.
- New products must have a Coming Soon page public for at least two weeks before
  release.
- Submit store presence for Valve review at least seven business days before
  the desired page-live date.
- Valve review commonly takes three to five business days, but plan buffer for
  changes and resubmission.
- Next Fest dates and themed festival eligibility are time-sensitive. Always
  check Upcoming Steam Events.

## Store Presence Checklist

Prepare:

- Steam app and permissions to edit metadata and publish app changes.
- Short description focused on the unique player-facing hook.
- Long description with clear feature sections and actual gameplay claims.
- Tags: at least five required before launch; up to twenty recommended.
- Trailer, preferably gameplay-led.
- Screenshots that show gameplay only.
- Capsule and library assets using current templates.
- Release date display.
- Pricing and package planning when relevant.
- Social links in allowed fields, not embedded into description body.
- Supported languages, mature content survey, platform support, and controller
  support claims aligned with the real build.

## Asset Baseline

Current Steamworks graphical asset overview lists:

- Header Capsule: 920 x 430.
- Small Capsule: 462 x 174.
- Main Capsule: 1232 x 706.
- Vertical Capsule: 748 x 896.
- Screenshots: minimum 1920 x 1080 or larger, 16:9.
- Page Background: optional, 1438 x 810.
- Shortcut Icon: 256 x 256 `.ico` or `.png`.
- App Icon: 184 x 184 `.jpg`.
- Library Capsule: 600 x 900.
- Library Hero: 3840 x 1240 `.png`.
- Library Logo: 1280 wide and/or 720 tall `.png`.
- Library Header Capsule: 920 x 430.
- Event Cover: 800 x 450.
- Event Header: optional, 1920 wide x 622.

Check Steam's current templates before production. Old dimensions may be
rejected.

## Copy Rules

- Short description should explain the unique value proposition quickly.
- Keep time-based phrases out of the short description.
- Do not include links in Steam description areas; use Steam's dedicated link
  fields.
- Do not use images or animations that mimic Steam UI, wishlist buttons, prices,
  or capsules.
- Do not advertise other games in the page description.
- Keep store claims honest and launch-aligned.

## Review Risk Checks

Flag these before review:

- Screenshots contain concept art, pre-rendered stills, marketing copy, awards,
  or non-gameplay imagery.
- Trailer or description shows incomplete or future-only features without clear
  expectation setting.
- Capsule art contains unreadable logo/title or disallowed marketing text.
- Description is vague, incoherent, link-heavy, or not focused on the product.
- Tags do not match actual player expectations.
- Platform/controller/language features are selected but not implemented.

## Wishlist and UTM Notes

- Wishlists become available once the page is public.
- Wishlist emails/push notifications can be triggered by launch, Early Access to
  full release, qualifying discounts, and associated demo release rules.
- Steam UTM Analytics can attribute page visits and conversions such as
  wishlists for properly tagged store-page links.
- Prefer consistent UTM names over ad hoc short links:
  `utm_source`, `utm_medium`, `utm_campaign`, and optionally `utm_content`.

## Next Fest Notes

- Steam Next Fest is for upcoming unreleased games with a public base game store
  page and a publicly playable demo by the event.
- A title can participate in only one Next Fest.
- Registration is done from the base game, not the demo.
- Demo review deadlines can be weeks before the event. Check the current event
  page and work backward from Press Preview and launch dates.
