# Provenance and maintenance

Generic delegation, self-contained assignments, bounded capacity, exact-session supervision, quota provenance, and verification concepts were adapted from [avenoxai/avenoxskills](https://github.com/avenoxai/avenoxskills/tree/8a8035a989ea02cd5605baf397082f43eae55aca), commit `8a8035a989ea02cd5605baf397082f43eae55aca` (MIT). Retained notice: [LICENSE](../LICENSE).

This package includes the adapted orchestration procedure only. It includes no upstream runtime, external fleet, account scanner, paid-provider fallback, video, thumbnail, or blockchain skill.

Agent Foundry's existing tracked studio scheduling was migrated into [tracked production](tracked-production.md). Role/rule/template resources remain in the legacy studio folder; its entry is an argument-preserving alias. Existing lifecycle skills retain contract, lock, defect, and closure authority.

Maintain this packaged source and validate adapters, catalog, manifest hashes, relative links, and forward scenarios. No machine-local shared skill root is required. Current user/repository policy overrides upstream examples and cost/model claims.
