Use `game-design-studio`. Add `unity-game-dev`, `firebase-game-backend`, or
`clean-oop-architecture` only when the design needs implementation planning or
technical boundaries.

Focus on:

- Core loop, progression, economy, risk/reward, pacing, fail states, and UX.
- Clear system rules, edge cases, data/config needs, and acceptance criteria.
- Implementation-ready notes without over-prescribing code.
