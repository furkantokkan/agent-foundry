# Clean OOP Architecture

The user invoked this command with: $ARGUMENTS

Use `clean-oop-architecture`. If the target is Unity, also use
`unity-game-dev`. If Firebase or JavaScript boundaries are involved, add the
matching backend/tooling skill.

Focus on:

- Single responsibility and clear reasons to change.
- Dependency inversion at Unity, Firebase, networking, UI, storage, and platform
  boundaries.
- Small role-specific interfaces only when they improve clarity or testability.
- Clear English names and simple method verbs.
- Testable domain logic without scenes, live services, or UI.
- Focused unit tests for new or changed expected behavior.

Proceed with the architecture/refactor task.
